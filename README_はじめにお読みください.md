# Jom! マレーシア！ 連載マンガ アーカイブ

週刊情報誌 Mtown の連載マンガを、だれでも無料で読めるサイト。

- **公開URL: https://jom-malaysia.github.io/**
- 置き場所: GitHub 組織 `jom-malaysia` のリポジトリ `jom-malaysia.github.io`
- ホスティング: GitHub Pages（無料・容量/アクセス制限なし・広告なし）

---

## 毎週の更新（これだけ覚えればOK）

```
1. 新しい回のPDFを images/<話数>/ フォルダに入れる
2. **「これを押して更新.bat」** をダブルクリック … 変換もサイト反映も全部これ1つ（1〜2分で反映）
```

### 通常の話

`images/23/` のように「話数の数字だけ」のフォルダを作り、中に:

| ファイル | 説明 |
|---|---|
| `第23話.pdf` | 本編（ファイル名に「話」か「本編」を入れる） |
| `おまけ.pdf` | 任意（ファイル名に「おまけ」を入れる） |
| `info.txt` | 任意（`タイトル:` と `掲載: 2026-06` を書ける） |

### 特別回（広告など、本編ではない回）

第23話と第24話のあいだに入れたいときは、フォルダ名を **`23-24特別回`** にして、中にPDFを1本入れる。

- ファイル名が一覧の副見出しに出る（例 `すずらん整体院.pdf` → 「すずらん整体院」と表示）
- 一覧では第23話と第24話のあいだに「特別回」バッジ付きで表示され、読書中も順番につながる

### 空のフォルダは表示されません

PDFが入っていないフォルダは、サイトに出ません。先に番号フォルダだけ作っておいてOK。

## サイトの機能

- トップ = バナー ＋「第1話から読む」「最新話を読む」＋ 話の一覧
- タブ 3つ: この漫画について / 登場人物 / おといあわせ
- 話をタップ → 読書画面（本編を大きく表示、おまけがあれば切替タブ）
- 各話の最後に「次の話を読む」ボタン（一覧に戻らず続けて読める）
- 読書画面の右下に「まんがの大きさ」ボタン（＋ / － / 100%に戻す）。まんがをタップしても拡大する
- 左右キー・スワイプで前後の話へ。スマホ最適化

## 素材の差し替え（バナー・登場人物など）

`HP素材/` に元画像を入れ替えて、`python scripts/prep_assets.py` を実行すると `assets/` の画像が作り直される。

| 差し替えるもの | 置き場所 |
|---|---|
| PC用バナー | `HP素材/PC用バナー.png` |
| スマホ用バナー | `HP素材/スマホ用バナー.png` |
| Mtownロゴ | `HP素材/Mtownロゴ.jpeg` |
| 作者アイコン | `HP素材/しまだなおき.png` |
| 登場人物7名 | `HP素材/HP用/<名前>.png` |

文言（紹介文・連絡先・登場人物の説明）は `site.js` を編集。

## こまったとき

- 「これを押して更新.bat」がエラー → コマンドプロンプトで `pip install pymupdf pillow` を一度実行してから再挑戦
- 画像が全部出ない → リポジトリ直下の `.nojekyll`（空ファイル）を消していないか確認。これは必須
- Mac の場合 → 「これを押して更新.bat」の代わりに `python3 build.py && git add -A && git commit -m 更新 && git push`

## 元PDFについて

各話の元PDF（`images/<話数>/*.pdf`）はサイトには**アップロードされません**（変換後の画像だけが公開されます）。
一度「これを押して更新.bat」で変換すれば、元PDFを外付けドライブ等に移してもサイトは動き続けます。
ただしバックアップとして保管しておくことを推奨します。
